# Mapové podklady ETS2

Použi oprávnene získaný export PMTiles v3 z projektu [TruckSim Maps](https://github.com/truckermudgeon/maps). Zdrojový kód projektu a herné mapové dáta môžu podliehať odlišným licenčným podmienkam.

- `ets2.pmtiles`: cestná sieť, vrstva `ets2`.
- `world.pmtiles`: voliteľný podklad, vrstvy `water` a `countries`.

V sekcii Mapa spoločnosti možno vybrať súbory lokálne bez odosielania na server. Pre automatické načítanie ich umiestni do tohto priečinka iba ak máš oprávnenie na publikovanie a hosting podporuje HTTP Range požiadavky. GitHub má limity veľkosti súborov. Samotné binárne mapové podklady zatiaľ nie sú súčasťou repozitára.

Mapové dáta: TruckSim Maps / Trucker Mudgeon; hra: SCS Software.
